# 레코드 위젯 Play 스토어 배포 안내

## 0. 준비물

| 항목 | 위치 |
|---|---|
| 앱 파일 (AAB) | GitHub 저장소 → Releases → 가장 최신 `Record Widget N` → `app-release.aab` (versionCode 17 / 2.6) |
| 앱 아이콘 512×512 | `promo/play/icon_512.png` |
| 대표 이미지 1024×500 | `promo/play/feature_1024x500.png` |
| 휴대전화 스크린샷 (1080×2160, 2:1) | `promo/play/screenshot_*.png` (2~8장) |
| 개인정보처리방침 | `VinylWidget/PRIVACY.md` 내용을 **공개 웹페이지**로 올린 주소 (아래 2-1) |

> 업로드 키(`upload.jks`)와 비밀번호는 저장소에 있으니 **저장소를 꼭 비공개로 유지**하세요.

## 1. 앱 만들기

1. [Play Console](https://play.google.com/console) → **앱 만들기**
2. 앱 이름 `레코드 위젯`, 기본 언어 `한국어`, 유형 `앱`, `무료`, 정책 동의 → 만들기

## 2. 앱 설정 (대시보드 → "앱 설정" 할 일 목록)

### 2-1. 개인정보처리방침
- Play는 **공개 URL**만 받습니다. GitHub 저장소가 비공개라 그 주소는 쓸 수 없습니다.
- 가장 쉬운 방법: Google Sites / Notion / 네이버 블로그에 `PRIVACY.md` 내용을 붙여 공개로 게시 → 그 주소를 입력

### 2-2. 앱 액세스
- "모든 기능을 특별한 액세스 권한 없이 사용 가능" (로그인 없음)

### 2-3. 광고
- "아니요, 광고 없음"

### 2-4. 콘텐츠 등급
- 설문 카테고리 `기타(유틸리티 등)` → 폭력·선정성 등 모두 "아니요" → 전체이용가 예상

### 2-5. 타겟층
- 만 18세 이상 (또는 13세 이상) 선택. 아동 대상으로 고르면 추가 정책 심사가 붙습니다.

### 2-6. 데이터 보안 (Data safety)
| 질문 | 답 |
|---|---|
| 사용자 데이터를 수집·공유하나요? | **예** |
| 전송 중 암호화? | **예** (Open-Meteo는 HTTPS) |
| 삭제 요청 방법 제공? | 저장하는 데이터가 없으므로 "아니요" 또는 해당 없음 |
| 위치 → **대략적인 위치** | 수집됨: **예** / 공유됨: **아니요**(날씨 서비스 제공업체에 앱 기능 수행 목적으로만 전달 = 서비스 제공업체 예외) / 일시적으로만 처리: **예** / 필수 여부: 선택(권한 거부 가능) / 목적: **앱 기능** |
| 그 외 (연락처, 사진, 앱 활동 등) | 수집 안 함 |

- 알림 접근 권한(곡명·앨범 커버)은 기기 안에서만 쓰고 밖으로 보내지 않으므로 "수집"에 해당하지 않습니다.

### 2-7. 정부 앱 / 금융 / 건강 / 뉴스
- 모두 "아니요"

## 4. 비공개 테스트 (새 개인 개발자 계정은 필수)

2023년 11월 이후 만든 **개인 개발자 계정**은 프로덕션(정식) 출시 전에
**테스터 12명 이상이 14일 연속 참여한 비공개 테스트**를 거쳐야 합니다.

1. **테스트 및 출시 → 테스트 → 비공개 테스트** → 트랙(Alpha) 관리
2. **테스터** 탭 → 이메일 목록 만들기 → 카페에서 받은 Gmail 주소 추가 (또는 Google 그룹)
3. **버전 만들기** → `app-release.aab` 업로드
   - 처음이면 **Play 앱 서명** 사용에 동의 (Google이 배포용 키를 관리, `upload.jks`는 업로드 키)
   - 출시 노트 예: `첫 테스트 버전입니다. 사용해 보시고 불편한 점을 알려주세요!`
4. **검토 → 출시 시작** → 첫 검토는 보통 며칠 걸립니다
5. 승인되면 **테스터** 탭의 **참여 링크(웹)** 를 카페 쪽지로 보내기
6. 테스터가 링크에서 "테스터 되기" → Play 스토어에서 설치 → **14일간 삭제하지 않기**

## 5. 정식 출시

1. 14일이 지나면 대시보드에 **프로덕션 액세스 신청**이 열립니다 → 설문(테스트 진행 방식, 받은 피드백) 작성
2. 승인 후 **프로덕션 → 버전 만들기** → 같은 AAB(또는 더 새 버전) 업로드 → 출시

## 6. 업데이트할 때마다

- `VinylWidget/app/build.gradle.kts`의 **versionCode를 1 올려야** Play가 받아줍니다 (versionName도 함께)
- 코드를 푸시하면 GitHub Actions가 자동으로 AAB를 만들어 Releases에 올립니다
