### 🎵 1. 레코드 위젯

📷 [사진 2: 02_record.png]

- 유튜브 뮤직으로 노래를 틀면 **레코드판이 돌아가고 톤암이 판 위로 내려와요**
- 지금 듣는 곡의 **앨범 커버가 레코드 라벨**이 돼요
- 위젯에서 바로 이전 곡 / 재생·일시정지 / 다음 곡 조작
- 크기: **2×2** (판 + 버튼), **1×4** (판 + 곡 제목·가수 + 버튼)

### ⛺ 2. 날씨·날짜 위젯

📷 [사진 3: 03_weather_designs.png]

- 오늘 날짜·요일 + 현재 기온·날씨·최저/최고 기온
- 디자인이 **2×2 7종, 1×4 3종** 있어요
  (LP 재킷 / 불 켜진 텐트 / 하늘 원 / 큰 날짜 + 텐트 / 미니멀 / 다이얼 / 달력, 1×4는 캠핑 파노라마 / 텐트 + 날짜 / 심플)

📷 [사진 4: 04_weather_changes.png]

- **맑음·흐림·비·눈 × 낮·밤**에 따라 그림이 바뀌어요
  밤이나 비 오는 날엔 텐트에 불이 켜져요 🔥
- 30분마다 자동으로 새로 받아오고, 위젯을 누르면 바로 새로고침돼요

### 🪟 3. 어떤 배경화면에도 어울리는 유리 카드

📷 [사진 6: 06_any_wallpaper.png]

- 위젯 바탕이 **반투명 유리 카드**라 어떤 배경화면 위에서도 튀지 않아요
- **배경화면 색을 따라** 카드와 버튼 색이 저절로 바뀌어요 (안드로이드 12+ Material You)
- **다크 모드**도 알아서 따라가요

### 🎨 4. 내 맘대로 꾸미기

📷 [사진 5: 05_customize.png]

- 배경 **자동(유리) / 검정 / 흰색**, **투명도 0~100%**
- 버튼·글자 색: **자동(배경에 맞춤)** + 기본 10색 + 직접 고르기(색상·채도·밝기, #색상코드 입력도 돼요)
- 미리보기에서 보이는 그대로 홈 화면에 들어가요
- 위젯을 길게 누르고 '설정'을 누르면 위젯마다 따로 꾸밀 수 있어요

### 🔐 권한 안내 (걱정 안 하셔도 돼요)

- **알림 접근**: 음악 앱의 곡 제목·앨범 커버·재생 상태를 위젯에 띄우는 데만 써요. 알림 내용은 읽거나 저장·전송하지 않아요.
- **대략적인 위치**: 날씨를 불러오는 데만 써요. 약 1km 단위로 뭉뚱그린 위치를 날씨 서비스(Open-Meteo)에 보내고, 저는 위치를 모으거나 저장하지 않아요.
- 광고 없음, 회원가입 없음, 그 밖의 개인정보 수집 없음
